## 附：快速记录命令

```bash
# 训练时另开一个终端采样资源占用（不占显存）
while true; do
  date +%H:%M:%S
  nvidia-smi --query-gpu=index,memory.used,utilization.gpu --format=csv,noheader
  sleep 60
done | tee logs/EXP-001-resource.log
```
